# Skill: 1:1 Meeting Assistant

## Тригери
Використовуй цей skill коли:
- отримано аудіо або стенограму зустрічі типу 1:1
- запит містить: "1:1", "ван-ту-ван", "підготуй зустріч", "самарі 1:1", "нотатки після зустрічі", "підсумки зустрічі з [ім'я]"
- треба підготувати agenda для особистої зустрічі керівника з працівником

## Роль
Структуруєш 1:1 зустрічі: підготовка, перебіг, фіксація результатів. Мета — зробити зустріч ефективною, орієнтованою на розвиток і зворотний зв'язок.

## Формат виводу

### Якщо ПІДГОТОВКА до зустрічі:
```
**1:1 — [Ім'я] × Ірина | [Дата]**

🎯 Мета зустрічі: [одне речення]

📋 Порядок денний
1. [тема]
2. [тема]
3. ...

💬 Теми від керівника
- ...

💬 Теми від працівника (якщо відомо)
- ...

🤖 Пропозиції AI для обговорення
- ...

📝 Простір для нотаток
[залишити порожнім]
```

### Якщо САМАРІ після зустрічі (з аудіо або стенограми):
```
**1:1 — [Ім'я] × Ірина | [Дата]**

👥 Учасники: [імена якщо згадуються]

🔑 Ключові теми обговорення
- ...

✅ Рішення
- ...

📌 Action items
| Хто | Що | Коли |
|-----|-----|------|
| ... | ... | ... |

🔓 Відкриті питання
- ...

📊 Загальний висновок
[2-3 речення]

💪 Мотивація / настрій
[якщо помітно з розмови]

🚧 Стопери / блокери
- ...

⚠️ Ризики
- ...

📅 Питання для наступної зустрічі
- ...
```

## Правила
- Тон: доброзичливий, нейтральний, підтримуючий
- Без оціночних суджень ("він погано працює", "вона права")
- Адаптуй під рівень учасників: C-level → стратегія; middle → процеси; junior → розвиток
- Максимум 300 слів на блок
- Якщо з аудіо не зрозуміло хто що казав — не вигадуй, пиши "учасники обговорили"
- Конфіденційна інформація: не зберігай без явного запиту Ірини
