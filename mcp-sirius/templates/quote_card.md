# quote_card

Editorial quote card with a serif quote, accent author tag, and handle.

## Variables

- `quote` *(required)* — the quote text, 1–3 sentences
- `author` *(optional)* — uppercase tag below the quote
- `handle` *(optional)* — @-handle or attribution, low-opacity
- `background_color` *(optional, default "#f4ede0")* — page background
- `text_color` *(optional, default "#1a1a1a")* — body text color
- `accent_color` *(optional, default "#c97b4b")* — quote mark + author color

## Example

```json
{
  "quote": "Перший рік у LinkedIn — це не про охоплення, це про послідовність.",
  "author": "Lesson learned",
  "handle": "@my.brand"
}
```
